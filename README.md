# Awesome-AI-Adoption-Analytics

Awesome AI Adoption AnalyticsCurated List of SaaS Products & Open-Source GitHub ProjectsFocused on AI Usage Measurement, Copilot Adoption, Sentiment Analysis & ROI TrackingLast updated: October 2026This repository tracks notable SaaS platforms and open-source projects for AI Adoption Analytics. These tools help organizations measure how employees adopt AI tools like Microsoft Copilot, GitHub Copilot, ChatGPT, and custom agents—tracking usage, sentiment, productivity impact, and license utilization.Examples include Microsoft Copilot Dashboard, Viva Insights, Worklytics, Qualtrics EmployeeXM, Prodoscore, ActivTrak, Teramind, Culture Amp, Workday Peakon, and Hubstaff (the category leaders).Open-source emphasis: AI adoption analytics has a growing open-source ecosystem driven largely by Microsoft's own Analytics Hub. AI-in-One (MIT) is the flagship open-source Power BI report for combining Copilot usage with Purview audit logs, agent telemetry, and sentiment surveys . GitHub Copilot Metrics Dashboard (MIT) provides a solution accelerator for visualizing Copilot adoption via the official Metrics API . copilot-usage-advanced-dashboard overlays Copilot usage with developer activity (commits, PRs) for true ROI analysis . ai-usage-measurement-framework detects AI tool usage from commit history and Agents.md files . This section documents these production-grade and research-grade solutions.Contributions welcome! Open a PR to add/update entries. Key differentiators vs. Viva Insights Copilot Dashboard: Combines Viva data with Purview audit logs, agent telemetry, sentiment surveys, or admin center exports in a single report; works without Viva license; full Power BI customization; prompt-level data via Chat Intelligence Report companion; agent telemetry via Agent Intelligence Report companion; cohort-level license utilization for finance conversations . Setup: ~30 min with Power BI Desktop + parameters. Data stays in tenant (local .pbit, you control refresh). Best for: Organizations needing deeper analysis than Viva provides, or those without Viva licenses .GitHub Copilot PanelOpen-source Power BI template for GitHub Copilot adoption (MIT licensed). Seven report pages walking a single funnel: Licensed → Active → Habitual → Deep → Valued . Key metrics: Engagement depth (not just seats used); acceptance rates by language; model adoption; team-level goal tracking with bright-spot/hotspot views . Data source: Viva Insights GitHub Copilot query or local CSV export . Best for: Engineering orgs wanting to understand developer AI adoption beyond seat counts .Copilot Adoption & Sentiment ReportOpen-source Power BI report correlating Copilot usage with employee survey sentiment (MIT licensed). Four report pages: Adoption Overview (licensed/active users by org and usage tier); Sentiment Analysis (survey scores correlated with actual Copilot activity); Comments Analysis (free-text survey responses categorized); Saved Time Analysis (self-reported daily time savings by usage tier) . Purpose: Surface where perception diverges from reality and focus enablement efforts . Best for: Organizations running Copilot Impact Surveys in Viva Glint/Pulse .ValueLensOpen-source Power BI report converting Copilot signals into hours saved, assisted value, and adoption maturity (MIT licensed). Key features: Adoption & reach, activity & value, usage maturity; Licence readiness — who to reassign, who to keep; SharePoint, Fabric, and Dataverse paths . Best for: Building defensible ROI stories for finance and procurement .Consumption CentralOpen-source Power BI template for Copilot credit consumption and cost across four products (MIT licensed). Covers: Cowork/Work IQ, Copilot Studio, GitHub Copilot, Azure AI Foundry — four portals become one view . Key features: Group spend by department, cost centre, country, manager; forecast to end of billing period; overage vs. prepaid packs; Local CSV, Fabric, and Viva Direct paths . Best for: FinOps and IT finance tracking Copilot spend .Agent EvaluatorOpen-source Power BI report analyzing Copilot Studio agents (MIT licensed). Reads conversation transcripts directly — every number has a real conversation behind it . Key metrics: Resolution and containment (designed handoffs counted as success); Topics, knowledge grounding, CSAT; ranked fix list . Best for: Teams building and improving custom Copilot Studio agents .GitHub Copilot Metrics ToolsGitHub Copilot Metrics DashboardMicrosoft's open-source solution accelerator for GitHub Copilot metrics (MIT licensed). Key features: Filters by date range, languages, code editors, teams; Acceptance Average; Active Users; Adoption Rate (active users / licensed users); Seat Information (active, inactive, total); Language and Code Editor breakdowns; Teams Filter for team-level insights . Data source: GitHub Copilot Metrics API and User Management API . Deployment: Local (npm run dev) or Azure (azd up) . Best for: Engineering organizations wanting a ready-to-deploy Copilot adoption dashboard .copilot-usage-advanced-dashboardOpen-source dashboard overlaying GitHub Copilot usage with developer activity metrics for true ROI analysis. Key innovation: Instead of showing Copilot stats in isolation, overlays Copilot usage with commits, pull requests, and code reviews from GitHub to correlate adoption with productivity changes . Data stored in Elasticsearch (not limited to 28 days like GitHub UI) for long-term trend analysis . Demo mode: Generates 5 months of realistic data (25 developers, 5 teams) with 20-30% productivity improvements post-adoption . Deployment: docker-compose up -d, Grafana at localhost:8080 . Best for: Engineering leaders wanting to prove Copilot ROI through actual developer output correlation .AI Usage Detection & Measurementai-usage-measurement-frameworkOpen-source framework to measure and analyze AI-assisted development in Git repositories. Key innovation: Detects usage of GitHub Copilot, Windsurf, Cursor, ChatGPT, Claude, and other AI coding tools by analyzing commit history and Agents.md files . Features: CLI for single repo or GitHub team analysis; Streamlit web dashboard with pie charts, bar charts, and timeline views; date filtering; export to JSON or CSV; extensible detection patterns . Usage: uv run ai-usage-measurement-framework analyze REPO or launch webapp . Best for: Engineering orgs wanting to measure AI tool adoption through commit patterns rather than API telemetry .YavioOpen-source analytics and visibility layer for MCP servers and ChatGPT Apps (MIT licensed, self-hosted). Captures how AI platforms (ChatGPT, Claude, Cursor, Windsurf, VS Code) invoke your tools and how users interact with widgets — tool calls, conversions, funnels, errors, retention . 3-line SDK integration: withYavio(new McpServer(...), { apiKey: "..." }) . Features: Zero-config MCP instrumentation; user identification; funnel tracking; cross-layer correlation; widget SDK (12 interaction types); full analytics dashboard; platform detection; PII stripping; multi-tenant workspaces . Architecture: ClickHouse for analytics, PostgreSQL for app data .
